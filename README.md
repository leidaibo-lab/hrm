# HRM

HRM（Human Resource Management）是一个基于 AI 能力进行产品探索与研发实践的项目，用于从产品发现开始，逐步明确目标用户、业务问题、MVP 范围和后续技术实现方案。

## 当前阶段

当前处于产品探索准备阶段：暂不锁定技术栈，也不直接编写业务代码。先通过结构化产品工作流确认 HR、员工、直属主管和系统管理员的核心场景，再决定是否进入 MVP 设计与实现。

## 工作原则

- 先验证问题，再设计功能。
- 先定义角色、权限和敏感数据边界，再讨论实现。
- 每次讨论沉淀为可追溯的产品文档。
- 产品范围确认前，不提前创建业务代码和数据库结构。
