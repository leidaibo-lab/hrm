# 测试资产

- `runs/<runId>/<stage>/<hash>/`：版本化测试计划、批准用例、逐项结果、登记检查日志、缺陷及回归历史，实际运行时归档。
- 后续可将可复用业务用例放 `cases/`、跨应用自动化放 `e2e/`；单元测试可留在应用所属模块，使用清单关联，避免重复维护。当前尚未生成这些测试。
- 测试集必须绑定产品版本、源码版本与执行环境；通过结果只能来自实际进程或标明来源的人工回执。

当前 .mjs 执行切片不能执行 HRM 的 Next/Nest 整仓测试。新增测试脚本编写/批准、用例复用及 pnpm/浏览器执行为待办。大体积日志/截图/视频需外部资产存储，Git 记录引用和散列。详见 [交付资产约定](../docs/delivery-assets.md)。
