## 二、产品规格（A）

### A1 功能目标与非目标

| 类型   | 内容                                                                                                                                                                                                                                                                           |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| 目标   | 可见：工单、线程、关注、产物、运行轨迹、审计、策略、来源、Agent 与模型网关在同一个控制台里可查，列表与详情信息一致。                                                                                                                                                           |
| 目标   | 可操作：在 Web 完成确认、驳回、回滚、撤销、结束、重开、回答关注、发布策略、启停来源与触发回归等重操作。                                                                                                                                                                        |
| 目标   | 触达面分级：来源 Channel 只做轻操作与通知，复杂操作跳转 Web；Web 是唯一的重操作与回放入口。                                                                                                                                                                                    |
| 目标   | 可回放：运行轨迹与审计按追踪标识还原角色、步骤、工具入参与结果、授权依据与产物，只读、不重放副作用。                                                                                                                                                                           |
| 目标   | 收敛可见性：页面按 Space 成员关系过滤数据，导航按权限点过滤条目，越界数据按不存在呈现。                                                                                                                                                                                        |
| 非目标 | 本期不接入具体业务场景，控制台只保留平台运维视图；不做移动端专门适配、批量改状态、页面直连数据存储或自建请求；不在前端做唯一权限判定，不实时渲染模型推理流，不修改 vendor 组件内部，不提供工单导出；不做多租户与部门视图；不在页面复制模型网关的限流、429 分类与失败转移判定。 |

### A3 功能逻辑与判定

**工单与线程**

| 规则     | 判定与行为                                                                                     | 失败分支                                                 |
| -------- | ---------------------------------------------------------------------------------------------- | -------------------------------------------------------- |
| 工单列表 | 支持全部/进行中/已结束、Space 筛选与按开启时间或超时优先排序；筛选写入地址栏，刷新与回退可恢复 | 无匹配结果 → 空态并提示接入来源；越权 Space → 不展示     |
| 工单详情 | 展示状态、类型、Space、开启时间、授权、产物、关注与派发；进行中可结束，已结束可重开            | 结束必须填原因；工单不存在或越权 → 提示不存在            |
| 工单轨迹 | 事件、结论、产物、派发、关注、回报按时间合并；可指定时间点回看当时快照                         | 无审计权限 → 提示不可见；时间非法 → 拒绝并提示           |
| 产物操作 | 仅当存在上一版本且工单进行中显示回滚；仅当产物已确认且工单进行中显示撤销                       | 已结束工单按钮禁用；直接调用被服务端拒绝                 |
| 线程     | 列表展示最近 50 条线程；详情展示摘要与版本、来源冲突、事件流（来源、处置、过滤原因）、关联工单 | 无数据 → 提示接入后形成时间线；不存在或越权 → 提示不存在 |

**待办关注**

| 规则       | 判定与行为                                                                | 失败分支                                         |
| ---------- | ------------------------------------------------------------------------- | ------------------------------------------------ |
| 列表       | 仅展示未关闭关注，按截止时间排序，逾期高亮；支持按类型筛选                | 无数据 → 空态提示；越权工单的关注不可见          |
| 回答       | 确认、修改、驳回三种决定；文本必填；回答后重新拉取并移出列表              | 文本为空 → 禁用提交；并发回答 → 其中之一返回 409 |
| 默认时限   | 待答关注默认 72 小时到期；升级与停滞复查间隔 24 小时；提醒窗口 12 小时    | 超时按策略升级给负责人并写审计                   |
| 关闭与超时 | 已关闭或已超时的关注再次提交返回 409 冲突；未关闭但逾期的高亮并按策略升级 | 升级对象缺失 → 记录异常并保留待办                |

**运行轨迹与审计**

| 规则       | 判定与行为                                                                                                         | 失败分支                                                      |
| ---------- | ------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------- |
| 运行轨迹   | 只读回放运行级记录：角色、结果、耗时、tokens、步骤、授权、策略版本、产物标识与失败原因                             | 无记录 → 空态；加载失败 → 展示错误与追踪标识                  |
| 工具轨迹   | 工具调用以可折叠组件展示入参与结果，默认收起，展开可见脱敏后的参数与输出                                           | 入参或结果缺失 → 只展示工具名；超长内容 → 截断预览            |
| 数据来源   | 轨迹取自 trace span 与审计记录，按 Space 成员关系过滤；不做实时流式渲染                                            | 脱敏字段缺失 → 按默认敏感键处理                               |
| 只读约束   | 回放不重新调用工具、不重新发送消息、不改变工单状态；不展示模型推理流                                               | 任意回放触发外部写 → 视为缺陷并告警                           |
| 审计与回放 | 列表按动作与追踪标识筛选、时间倒序、固定分页；回放按追踪标识聚合运行、步骤、产物与授权依据；无可见记录按不存在处理 | 无记录 → 空态；页码越界 → 停留末页；不存在或越权 → 提示不存在 |

**策略、来源与 Agent**

| 规则         | 判定与行为                                                                                                    | 失败分支                                                             |
| ------------ | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------- |
| 策略         | 展示当前版本；发布后生成新版本、旧版本保留；准入表按当前版本读取与追加                                        | 无策略 → 按空表单展示；发布失败 → 展示错误不丢输入                   |
| 准入表       | 以来源实例、名单行、点名与准入单元格构成规则；准入判定只在接入层执行                                          | 同一单元格重复 → 拒绝并提示                                          |
| 来源与健康   | 列表展示启停并汇总健康（未上报、正常、启动中、异常）；新建飞书来源需名称、群与机器人标识；可编辑、启停        | 必填缺失 → 禁用提交；保存失败 → 展示错误；健康读取失败 → 显示未知    |
| 授权         | 来源的 Space 范围授权可查询与撤销；撤销后下一分钟停止读取                                                     | 撤销失败 → 提示重试；已撤销 → 幂等成功                               |
| Agent 与回归 | 展示 AgentSpec 清单与最近回归结果；阈值显式优先，否则取当前策略阈值，再缺省为默认值；不自动发布、不自动改状态 | 未登记 AgentSpec → 提示无可用用例；依赖不可用 → 提示且不产生发布动作 |

**模型网关设置**

| 规则 | 判定与行为                                                               | 失败分支                                                   |
| ---- | ------------------------------------------------------------------------ | ---------------------------------------------------------- |
| 视图 | 展示供应商、模型、目录、价格版本、用量与成本；用量按 Space 与 Agent 归因 | 无配置 → 空态引导接入供应商；读取失败 → 展示错误与追踪标识 |
| 凭据 | 只显示凭据引用与状态，不显示明文密钥；密钥不进页面数据                   | 请求明文凭据 → 不返回该字段                                |
| 边界 | 限流、429 分类、失败转移与计量由网关负责，页面只呈现结果                 | 页面不提供绕过网关的路由改写                               |

**卡片轻操作与权限**

| 规则       | 判定与行为                                                                                                                                    | 失败分支                                             |
| ---------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 轻操作     | 卡片只承载确认、驳回、补充信息与打开 Web 链接；复杂编辑、批量操作、回放一律跳转 Web 页面                                                      | 不支持的动作 → 拒绝并提示到 Web 处理                 |
| 幂等       | 同一消息同一动作重复点击只执行一次，重复回调返回同一结果                                                                                      | 重复点击 → 不产生第二条记录                          |
| 失效与发送 | 关注已关闭或超时后点击卡片则拒绝并提示到 Web；卡片或通知发送失败按外部副作用规则转 gone 并留证                                                | 告警自身失败不再递归；未配置告警只保留关注与审计     |
| 权限判定   | 权限只在服务端判定；资源可见性来自 Space 成员关系，对象级判定在应用服务完成，前端不复制判定；页面按会话权限重定向或隐藏入口，按钮禁用只是展示 | 越权访问 → 403 页面展示所需权限点；越权数据 → 不可见 |
| 菜单可见性 | 导航按权限过滤，子项全部被裁剪时整组隐藏；菜单隐藏不是安全边界                                                                                | 直接输入无权地址 → 重定向 403，不依赖菜单            |

### A4 状态与数据流转

本域不持有业务状态，页面展示的是其他功能域的只读投影。

| 页面组 | 数据来源（只读投影）                                                 | 刷新时机                     | 失败表现           |
| ------ | -------------------------------------------------------------------- | ---------------------------- | ------------------ |
| 工单   | 工单、授权、产物、关注、派发、轨迹                                   | 进入页面、操作成功后失效重取 | 空态、错误态或 403 |
| 线程   | 线程摘要、事件流、关联工单、冲突                                     | 进入页面与切换线程           | 空态或不存在提示   |
| 待办   | 未关闭关注与工单摘要                                                 | 进入页面、回答成功后重取     | 空态；冲突提示     |
| 控制台 | 运行级审计、追踪聚合、策略、准入、来源健康、Agent 回归、模型网关用量 | 进入页面、筛选、发布或启停后 | 空态或错误提示     |

| 链路       | 起点        | 过程                                                  | 终点                     | 失败分支                                |
| ---------- | ----------- | ----------------------------------------------------- | ------------------------ | --------------------------------------- |
| 列表到详情 | 工单列表    | 选择工单 → 详情 → 轨迹 → 按追踪标识回放               | 一次运行的完整证据链     | 记录不存在 → 提示；越权 → 404 语义      |
| 待办回答   | 待办关注    | 填写文本 → 选择确认/修改/驳回 → 重新拉取列表          | 关注关闭、工单按决定推进 | 409 → 提示刷新；权限不足 → 403          |
| 审计定位   | 审计列表    | 按动作或追踪标识筛选 → 查看详情 → 回放                | 可解释的运行与操作记录   | 无记录 → 空态；追踪不可见 → 提示不存在  |
| 回归触发   | 管理员或 CI | 触发 AgentSpec 回归 → 查看分数与缺失关键词 → 留存审计 | 发布前的人工判断依据     | AgentSpec 不支持或依赖不可用 → 明确提示 |
| 卡片轻操作 | 来源卡片    | 点击确认/驳回 → 回调归到工单 → Web 可见结果           | 关注关闭或工单推进       | 重复点击幂等；失效或未映射 → 拒绝/忽略  |

### A5 交互与异常

| 场景           | 表现                                                                                                                          |
| -------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 加载中与空态   | 列表与详情显示骨架屏，不阻塞页面框架；工单、线程、待办、轨迹、审计分别给出为何为空与下一步建议                                |
| 无权限与失败   | 无权限重定向 403 并展示所需权限点与返回工作台入口；不存在与失败按不存在提示，不泄露存在性，展示可读错误并保留错误码与追踪标识 |
| 筛选与回退     | 工单筛选写入地址栏，刷新与浏览器回退保持当前筛选                                                                              |
| 冲突           | 并发回答、重复操作返回 409 并提示刷新后重试，不静默成功                                                                       |
| 回归失败       | 展示总分、阈值与未命中的关键词，不自动发布、不自动改状态                                                                      |
| 卡片重复或失效 | 重复点击返回同一结果；已关闭或超时提示到 Web 查看与处理                                                                       |
| 模型网关不可用 | 展示错误与追踪标识并保留筛选条件，不展示过期容量结论                                                                          |

### A6 扩展与接入点

| 类别       | 接入点                                                                                             | 约束                                                                                                           |
| ---------- | -------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------- |
| 数据接入点 | 审计与追踪聚合（trace span 与审计记录）                                                            | 只读；按 Space 成员关系过滤；不修改审计记录；无可见记录按不存在返回                                            |
| 数据接入点 | 工单、线程、待办、产物、策略、来源、Agent 与模型网关的页面视图                                     | 只经统一数据出口取数；不直连数据存储；业务规则不复制到页面                                                     |
| 数据接入点 | 会话、权限点、Space 成员与导航节点                                                                 | 由 iam 提供；权限点与导航目录同源；页面不得自造权限判定                                                        |
| 扩展点     | 新增页面与导航节点                                                                                 | 路由按域收敛：`/agentic/{tickets,threads,attention,console/*}`；平台设置页按各自领域前缀；登记权限点与导航节点 |
| 扩展点     | 新增前端切片                                                                                       | 按「页面域/功能」分组，跨切片只经出口；共享类型与查询键放共享层                                                |
| 扩展点     | 新增轨迹展示                                                                                       | 只消费已脱敏的轨迹字段；只读；不引入实时推理流；新增组件不修改 vendor 内部                                     |
| 扩展点     | 新增卡片动作                                                                                       | 必须是轻操作或跳转链接；幂等键稳定；失效与重复必须可判定                                                       |
| 接入禁止项 | 前端做唯一权限判定、自建请求、直写业务状态、回放触发外部副作用、展示未脱敏参数、页面绕过网关改路由 | 一律拒绝；权限以服务端判定为准，需要原文时按权限回查来源                                                       |

### B2 数据表

本域无自有数据表，只读投影其他功能域与平台表。

| ------------------------------------------------------------------------------------------------------------ | ------ | ---------------------------------------------------- |
| 审计记录与运行轨迹（`audit_logs`、`agentic_trace_spans`）                                                    | 证据面 | 审计列表与追踪回放只读                               |
| 工单、授权、产物、关注、派发、线程、事件、效果与出站（`agentic_*`）                                          | 01–05  | 工单列表/详情/轨迹、待办、产物区、线程列表与详情只读 |

### B3 接口与队列

| 方法 | 路径                              | 权限                   | 入参                                                               | 失败分支                                               |
| ---- | --------------------------------- | ---------------------- | ------------------------------------------------------------------ | ------------------------------------------------------ |
| GET  | `/agentic/audit`                  | `agentic.audit:read`   | action、actorId、traceId、spaceId、offset、limit（1–200，缺省 50） | 无权限 403；无记录返回空列表；结果按 Space 过滤        |
| GET  | `/agentic/audit/traces/:traceId`  | `agentic.audit:read`   | 追踪标识                                                           | 无权限 403；无可见记录 404；返回运行、步骤、产物、依据 |
| POST | `/agentic/agents/:key/regression` | `agentic.agent:update` | 可选 threshold（0–1，不含 0）                                      | 无权限 403；AgentSpec 不支持 400；策略或模型不可用 503 |

- 页面取数复用本域端点：工单、线程、待办、策略与准入、来源与授权分别由 01–05 域提供；本域不重复定义这些契约。
- 本域不新增队列；回归触发写审计动作，不写业务状态。飞书卡片动作回调归到工单与关注，不新增第二套判定。

### B4 运行时与框架

| 项         | 设计                                                                                                                                 |
| ---------- | ------------------------------------------------------------------------------------------------------------------------------------ |
| 渲染       | App Router：页面为服务端组件，逐请求取会话与权限；面板为客户端组件                                                                   |
| 会话与代理 | 统一会话入口从 cookie 换取会话，401 重定向登录；无权限重定向 403 并带所需权限点；代理只做 cookie 存在性乐观检查，真正鉴权在 API 守卫 |
| 取数       | 生成客户端是唯一数据出口；TanStack Query 管缓存与失效；按域前缀与工单键失效，不手写请求                                              |
| 查询键     | 域前缀统一，工单列表按筛选参数、工单详情按标识、待办按类型分别缓存                                                                   |
| 导航       | 导航节点来自统一导航目录，按权限过滤，组内全部被裁剪时整组隐藏；菜单隐藏不作为安全边界                                               |
| 轨迹展示   | `components/ai-elements` 的工具组件展示脱敏工具入参与结果；组件为 vendor，原样使用                                                   |
| 筛选状态   | 工单筛选写入地址栏，使用浏览器历史替换而非新增记录；组件初始化时从地址栏恢复                                                         |
| 模型网关页 | 只渲染网关读模型；凭据只显示引用；页面不实现限流、429 分类与失败转移                                                                 |
| 错误       | 请求错误保留错误码、HTTP 状态与追踪标识，页面展示可读文案                                                                            |
| 只读回放   | 回放只读接口数据，不触发执行、不写业务状态；轨迹数据来自审计详情，不做实时流式渲染                                                   |
