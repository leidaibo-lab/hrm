## 二、产品规格（A）

### A1 功能目标与非目标

| 目标       | 说明                                                                               | 平台指标                                       |
| ---------- | ---------------------------------------------------------------------------------- | ---------------------------------------------- |
| 事件可靠   | 外部事件经 Source 接入，先确认并持久化、提交后入队，不在请求内调用模型             | 接入确认 P95 ≤ 3 秒；请求内模型调用 0 次       |
| 一次一件   | 同一空间内重复投递、长连接重投不产生第二个 Trigger 或第二个 Thread                 | 重复事件二次落库 0；同对象线程唯一键冲突 0     |
| 来源可治理 | Source 按实例开通、配置、启停、授权与撤销；同一空间内同一对象的事件归并同一 Thread | 未授权落库 0；撤销后停止接收；同对象线程数 = 1 |
| 归属清晰   | 原始事件只由 Source 插件翻译为 Trigger；领域状态只由 Engine 写                     | Source 直写领域表 0；不可翻译事件不落库        |
| 出站可控   | Source 提供 Channel：发送、允许范围与链接；出站消息只经统一 Outbox 投递            | 重复发送 0；永久不可达只记录一次失败           |

非目标：本期不接入具体业务场景（业务能力由后续 AgentSpec 接入），只交付 Super-agent 平台能力；不判断「接不接」（归研判 02）；不执行任务、不做任务内容加工；不做工单、闸门、产物与写回决策；不管理平台用户、角色与空间（空间与成员关系由 iam 维护）；空间可见性只按 Space 成员关系判定，本期不引入关系型资源授权服务。Source 只交付契约与一个参考实现（Lark），不做多租户与部门、不做跨实例中继。本期飞书只做消息与卡片：不读取多维表格、不维护表格读取位置、不做表格写回。

### A2 角色与入口

| 角色                 | 入口                                   | 权限点                                       | 可做什么                                                | 不可做什么                       |
| -------------------- | -------------------------------------- | -------------------------------------------- | ------------------------------------------------------- | -------------------------------- |

| Executor（系统）     | 不直连来源，按工单经订阅取上下文       | —                                            | 按工单读取事件上下文                                    | 不读来源凭据；不直接对外发言     |

### A3 功能逻辑与判定

#### 3.1 飞书长连接（优先）

| 规则 | 说明                                                                                 | 失败分支                                           |
| ---- | ------------------------------------------------------------------------------------ | -------------------------------------------------- |
| 连接 | 以应用凭据建立长连接；只订阅消息与卡片动作事件；不读取多维表格，不接收表格变更       | 凭据缺失或鉴权失败不建立连接，健康置 error         |
| 重连 | 断线按指数退避重连（1 秒起、上限 60 秒）；重连后平台可能重投事件，由空间内幂等键去重 | 重连期间不接收；连续多次失败置 error，恢复后 ready |
| 接收 | 事件进入与回调相同的翻译、范围、授权、落库链路；不维护本地读取位置                   | 单条事件翻译失败丢弃并记日志，不拖垮连接           |
| 健康 | 记录连接状态、最近事件时间与连续失败次数                                             | 上报写失败只告警，不影响接入                       |

#### 3.2 回调接入（备选）

| 顺序 | 判定       | 规则                                                                                                                     | 失败结果                  |
| ---- | ---------- | ------------------------------------------------------------------------------------------------------------------------ | ------------------------- |
| 1    | 验签授权   | 加密体先解密；签名 = sha256(时间戳+nonce+加密密钥+原始体)；时间戳偏差 ≤ 300 秒；nonce 5 分钟内只接受一次；token 必须匹配 | 403，不落库               |
| 2    | 挑战应答   | `url_verification` 直接回 `challenge`，不产生事件                                                                        | —                         |
| 3    | 入站限流   | 每实例每秒配额（默认 20）                                                                                                | 429，上游退避重试，不落库 |
| 4    | 翻译与范围 | 自身消息、空文本、不可识别结构丢弃；群白名单、接收模式与私聊放行                                                         | 成功但不落库（静默）      |
| 5    | 授权判定   | 以空间授权记录为准；撤销或到期即拒绝                                                                                     | 成功但不落库（静默）      |
| 6    | 幂等落库   | 空间内幂等键唯一；重复投递返回已有 Trigger                                                                               | 成功，不重复入队          |
| 7    | 内联与入队 | 落库后交 Engine 在接入链路内联过滤并只把慢路径事件入队；请求内不调用模型、不等待研判                                     | 入队失败交上游重试        |

以上判定顺序是 Source 契约的参考实现（Lark）回调分支；回调只做验签、翻译、范围与授权校验、落库与交接，不在请求内调用模型；静默丢弃不回执，避免暴露授权状态。长连接与回调共用同一翻译、落库与内联链路。

#### 3.3 来源授权

- 维度内容：实例 + 空间（可选再细分会话范围）唯一；记录授权人、有效期（空为长期）、撤销时间；重复授权视为更新并清除撤销状态。
- 空间边界：授权按空间生效；事件所属空间未授权即拒绝，不跨空间复用授权记录。
- 判定兼容：已撤销或到期即失效，有效期必须晚于当前时间；无任何授权记录时按实例配置的名单放行，一旦有记录则未列出范围全拒绝。
- 撤销效果：撤销后新事件立即拒绝；已落库事件不回溯撤回。

#### 3.4 事件幂等与线程归并

- 幂等键来源内稳定：消息用消息 ID，卡片动作用动作事件标识；同一空间内同一幂等键只允许一条 Trigger。
- 线程键指向「同一个对象」；线程唯一键为「空间 + 来源类型 + 线程键」，同一线程键的事件归并到同一 Thread；自身消息、机器人消息与不可翻译事件不产 Trigger。
- 一个对象只属于一个空间：越空间的事件不归并、不建单；线程键必须带空间命名空间。
- 线程首见并发先查后建，唯一约束兜底；冲突回查复用已存在 Thread，仍失败则接入失败交上游重试。

#### 3.5 入站限流

- 回调按实例固定窗口每秒计数，默认 20 条/秒；超限回调返回 429 让上游退避，不落库。
- 长连接侧按每实例每秒投递速率做硬水位保护：超限只记告警并延迟消费，不丢事件；入口只在硬水位拒绝或断开。
- 计数依赖不可用时放行并告警：接入不阻断，但超限保护暂时失效，需人工关注。

#### 3.6 入口内联与入队

- 交接点：Trigger 落库后由 Engine 在接入链路内联完成硬过滤、Gate 与订阅直通（判定细节见 [02-triage.md](02-triage.md)），只有需要模型的慢路径事件进入 triage 队列；请求内不调用模型、不等待研判。
- 入队失败：回调交上游重试；长连接无确认语义，由周期扫描补入队；重试命中幂等不重复入队。
- 暂停：暂停期间照常落 Trigger、不启动新研判、不发回复；恢复后按当前策略复核。

#### 3.7 来源健康与启停

- 健康条目：以「实例 + 条目」记录（长连接与回调至少各一条）；状态 starting/ready/error/paused；连接状态与每批接入更新，写失败只告警。
- 启停：停用后不接受新事件、不建立或保持连接；已入队任务继续消费；启用后恢复接收；实例不存在或停用时事件静默丢弃，管理接口返回明确错误；连续失败才置 error，成功即回 ready。

### A4 状态与数据流转

| 对象     | 状态                                          | 流转                                                        | 触发者        |
| -------- | --------------------------------------------- | ----------------------------------------------------------- | ------------- |
| 来源实例 | 启用 / 停用；健康 starting/ready/error/paused | 启用 ↔ 停用；健康 starting→ready/error→ready                | 管理员/接入   |
| 来源授权 | 有效 / 已过期 / 已撤销                        | 有效 → 过期或撤销；再次授权 → 有效                          | 时间 / 管理员 |
| Trigger  | pending / filtered / evaluated / fanned_out   | pending → 三终态之一，仅一次                                | Engine        |
| Thread   | open / dormant / closed                       | open → dormant（长期无事件）；open/dormant → closed（人工） | 时间 / 人工   |

| 链路       | 输入                    | 变化                                 | 输出                 | 失败分支                               |
| ---------- | ----------------------- | ------------------------------------ | -------------------- | -------------------------------------- |
| 长连接接入 | 平台消息与卡片事件      | Trigger pending；Thread 新建/复用    | 落库、内联过滤与入队 | 翻译失败丢弃；重连重投由空间内幂等去重 |
| 回调接入   | 平台回调事件            | Trigger pending；Thread 新建/复用    | 落库、内联过滤与入队 | 验签/限流/范围/授权失败 → 拒绝且不落库 |
| 入口内联   | Trigger 主键 + 策略快照 | Trigger → filtered/fanned_out 或入队 | 慢路径任务、健康视图 | 入队失败补入队；健康写失败告警         |
| 来源治理   | 实例配置与授权          | 启用/停用；授权生效/撤销             | 实例与授权视图、健康 | 配置非法拒绝；授权过期或撤销拒绝接入   |

### A5 交互与异常

| 场景                                                            | 对用户/上游表现    | 系统处理                               | 可观察结果                             |
| --------------------------------------------------------------- | ------------------ | -------------------------------------- | -------------------------------------- |
| 验签失败、超窗、nonce 重复、未配密钥、token 错                  | 403，无业务提示    | 拒绝请求，不落库                       | 响应状态码；无 Trigger 记录            |
| 实例不存在/停用、自身消息、空文本、范围外、未授权、过期或已撤销 | 返回成功，无回执   | 静默丢弃，不落库                       | 无 Trigger 记录；授权视图 active=false |
| 达到每秒配额                                                    | 429                | 不落库；上游退避后重试                 | 限流响应；恢复后只落库一次             |
| 重复投递同一事件（含长连接重投）                                | 返回成功，无副作用 | 幂等命中，返回已有 Trigger             | Trigger 数与队列任务数不变             |
| 长连接断开或重连                                                | 无用户感知         | 指数退避重连；期间事件由平台补发并去重 | 连接日志、健康状态、Trigger 数         |
| 管理接口配置非法 / 名称冲突 / 授权有效期非法                    | 明确错误提示       | 拒绝保存                               | 接口错误；实例与列表不变               |
| 队列不可用 / 慢路径入队失败                                     | 无用户感知         | 回调交上游重试；长连接由周期扫描补入队 | 队列任务数、补入队记录                 |

### A6 扩展与接入点

#### 数据接入点

| 接入点       | 数据                                                                                              | 约束                                                 |
| ------------ | ------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| 长连接与事件 | 应用凭据、事件类型（消息/卡片动作）、事件体、空间、幂等键、线程键、范围、发起人、文本、负载、点名 | 只订消息与卡片；不读多维表格；幂等键稳定             |
| 回调与挑战   | 加密或明文事件体、签名头、nonce、时间戳；`url_verification` 挑战                                  | 必须带验签信息；挑战原样返回且不产生事件             |
| 出站 Channel | 回复地址（群/消息）、允许范围、链接                                                               | 按消息幂等键发送；只由统一 Outbox 调用；不做表格写回 |

#### 扩展点

| 扩展轴         | 接入方式                                                        | 必须满足                                                               |
| -------------- | --------------------------------------------------------------- | ---------------------------------------------------------------------- |
| 新 Source 插件 | 实现来源契约（事件翻译、Channel、配置 schema、健康）并注册 kind | 幂等键稳定、线程键指向同一对象、过滤自身消息、范围可判定、空间归属明确 |
| 新实例与名单   | 新增实例配置；由策略配置允许的源内成员与平台用户                | 配置由插件 schema 校验；密钥只存引用；名单只影响准入                   |

#### 接入约束与禁止项

- 必须提供空间归属、幂等键、线程键、来源范围、发起人与机器人标识，缺失任一项不接入；不得在回调请求内同步调用模型或执行任务，不得绕过验签、token、限流与授权。
- 不得为个别消息临时放宽范围；不得把授权状态、密钥、原始敏感内容写入日志或下游上下文；不得跨空间复用线程键，未授权事件不落库。
- 本期飞书只做消息与卡片：不读取多维表格、不维护表格读取位置、不做表格写回；Source 与 Channel 不得直接写领域表、不得自建工单；出站只经统一 Outbox。

### B2 数据表

本域归属 6 张表（总览见 [design.md](design.md) 第七节）：

| 表                              | 关键字段                                                                                                                                       | 约束/索引                                                              | 写入方         |
| ------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------------------------- | -------------- |
| `agentic_source_instances`      | id、sourceType、name、config、botId、enabled、createdAt、updatedAt                                                                             | (sourceType, name) 唯一；enabled                                       | 来源管理用例   |
| `agentic_source_health`         | instanceId、entry、state、detail、checkedAt、updatedAt                                                                                         | 主键 (instanceId, entry)；state+checkedAt                              | 连接与接入上报 |
| `agentic_source_authorizations` | id、sourceInstanceId、spaceId、scopeValue、authorizedBy、expiresAt、revokedAt、createdAt                                                       | (sourceInstanceId, spaceId, scopeValue) 唯一；expiresAt                | 授权用例       |
| `agentic_triggers`              | id、spaceId、dedupeKey、sourceType、instanceId、threadId、actorId、addressed、text、payload、occurredAt、receivedAt、disposition、filterReason | (spaceId, dedupeKey) 唯一；threadId+occurredAt；(spaceId, disposition) | Engine.Intake  |
| `agentic_threads`               | id、spaceId、sourceType、externalKey、status、summary、summaryVersion、lastEventAt                                                             | (spaceId, sourceType, externalKey) 唯一；status+lastEventAt            | Engine.Intake  |
| `agentic_reply_targets`         | id、threadId、sourceType、addressKey、address、createdAt                                                                                       | (threadId, addressKey) 唯一                                            | 出站回写用例   |

事件、授权与健康均以源实例为事实外键；Trigger 与 Thread 带 spaceId，Space 与成员属 iam（见 PRD-IAM），本域只引用标识，不做跨域外键。实例停用不删除历史数据；Thread 关闭后保留 1 年、事件 90 天归档、授权按合规保留。

### B3 接口与队列

HTTP 入口由 `source.controller.ts` 承载；接口清单与权限见 [design.md](design.md) 第八节。

| 接口           | 权限/鉴权               | 请求要点                            | 响应要点                                    | 失败分支                                         |
| -------------- | ----------------------- | ----------------------------------- | ------------------------------------------- | ------------------------------------------------ |
| 回调入口       | 公开 + 验签/token/限流  | 加密或明文事件体                    | `challenge` 或确认码                        | 403 验签/token/nonce；429 限流；其他错误上游重试 |
| 来源实例增改查 | `agentic.source:update` | sourceType/name/config/botId        | 实例视图或 `{items}`（最多 50）             | 配置非法 400；名称冲突 409                       |
| 实例启停       | `agentic.source:update` | —                                   | 实例视图                                    | 实例不存在 → 拒绝                                |
| 健康查询       | `agentic.source:update` | —                                   | `{items:[{entry,state,detail?,checkedAt}]}` | 未授权 401/403                                   |
| 授权增删查     | `agentic.source:update` | spaceId、scopeValue、expiresAt 可选 | `{items}`，含 `active` 判定                 | 空间为空/有效期非法 → 拒绝，不保存               |

| 队列             | job                           | 生产方                  | 消费方                 | 并发/顺序                 | 负载要点                                                                 |
| ---------------- | ----------------------------- | ----------------------- | ---------------------- | ------------------------- | ------------------------------------------------------------------------ |
| `triage.pending` | 慢路径研判（按 Trigger 幂等） | Engine.Intake（内联后） | Engine.Evals（worker） | 同 thread 串行；重试 2 次 | spaceId、triggerId、threadId、实例、范围行、点名、发起人、来源、发生时间 |

jobId 由 Trigger 主键派生，队列适配器统一净化自定义 ID 中的分隔符并追加摘要，重复投递只保留一个任务；消费入口先判 Trigger 是否仍待处理并检查暂停开关。

### B4 运行时与框架

Source 契约落地（对应 [design.md](design.md) 第八节 8.4）：

| 契约部分                        | 落地                              | 约束                                                                                |
| ------------------------------- | --------------------------------- | ----------------------------------------------------------------------------------- |
| kind / schema / fields / health | `schema.ts`、`source.ts`          | kind 稳定；配置 schema 校验；默认配置收不到事件                                     |
| 事件翻译                        | `translate.ts`                    | 稳定 dedupeKey、线程键、actor、human/addressed、channel、meta；自身消息不产 Trigger |
| scope                           | `source.ts`                       | 只看 meta 与配置；范围外交 Engine 记为 filtered；群白名单/接收模式/私聊             |
| Policy 名单                     | `source.ts` 暴露给 Policy         | 名单、准入行、bot 名单；不跨源映射身份                                              |
| channel                         | `channel.ts`                      | send/allowed/link；按消息 id 幂等；仅永久不可达返回 gone；只发消息与卡片            |
| environment                     | `source.ts`、`application/setup/` | 只传事实（sourceType、instanceId、spaceId），不传凭据                               |
| 生命周期                        | `source.ts`                       | 等 setup、跟随启停、abort、连续失败才报 error；断线指数退避重连                     |

| 项         | 设计                                                                                                                                                  |
| ---------- | ----------------------------------------------------------------------------------------------------------------------------------------------------- |
| 回调安全   | AES-256-CBC 解密（密钥 sha256 派生）；sha256 签名常量时间比对；300 秒窗；nonce 去重；token 匹配                                                       |
| 长连接     | 应用凭据建连；只订消息与卡片动作；指数退避重连（1 秒起、上限 60 秒）；重投由空间内幂等键去重；无本地读取位置                                          |
| 限流       | Redis 固定窗口每秒计数、按实例分键、默认 20；回调超限 429；长连接超限延迟消费并告警；不可用时放行并告警                                               |
| 持久与降级 | 仓储按 [design.md](design.md) 第七节；Trigger/Thread 唯一约束兜底；健康与审计写失败只告警；数据库不可用停止消费；入口只做廉价持久化与入队，不承担研判 |

### B6 实现决策索引

| ADR      | 结论                                                                |
| -------- | ------------------------------------------------------------------- |
| ADR-0042 | 外部事件归一为不可变 Trigger，接入与研判解耦，内核不执行业务。      |
| ADR-0043 | Source、Trigger、Thread 是独立事实，线程按空间、来源与外部键唯一。  |
| ADR-0050 | 来源授权记录授权人、空间范围、有效期与撤销，接入时校验。            |
| ADR-0070 | 自定义 jobId 由队列适配器统一净化，保持同键去重。                   |
| ADR-0072 | 线程并发首见以唯一键兜底，冲突回查并复用已存在线程。                |
| ADR-0077 | 单模块结构：Lark 作为 Source 插件落在 infrastructure/sources/lark。 |
| ADR-0078 | 平台优先范围：只交付平台能力与一个参考 Source，不作为业务场景立项。 |
