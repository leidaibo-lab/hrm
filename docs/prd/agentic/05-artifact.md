## 二、产品规格（A）

### A1 功能目标与非目标

| 类型   | 内容                                                                                                                                                                                                                                              |
| ------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| 目标   | 产物可追溯：任务产物与工作流产物以版本链保存，确认、回滚与撤销都能还原当时内容与操作者。                                                                                                                                                          |
| 目标   | 出站可约束：只向来源会话发送消息与卡片，载荷按策略白名单裁剪，未声明字段不出现；每次出站有稳定幂等键，重复触发不重复发。                                                                                                                          |
| 目标   | 外部写只做一次：成功结果可重放、失败可重试、gone 不重发；发送与记账之间的崩溃不让外部系统收到第二条。                                                                                                                                             |
| 目标   | 失败可见：出站 gone、连续失败与结果未知都有审计、关注或告警，不允许静默丢弃。                                                                                                                                                                     |
| 非目标 | 本期不接入具体业务场景，不定义业务产物语义；不读写来源系统的业务表格与字段（不做多维表格写入，也不维护表格游标）；不做代码执行、建分支、提 MR，不接管来源系统自身的字段校验与审批；不做跨实例产物共享与大对象存储，不向外部系统推送模型推理过程。 |

### A2 角色与入口

| 角色       | 本域可做的事                                                    | 入口                         | 前置权限                                                       |
| ---------- | --------------------------------------------------------------- | ---------------------------- | -------------------------------------------------------------- |
| 请求人     | 查看任务产物与出站结果；在评审关注上确认、修改、驳回            | 来源卡片、工单详情、待办关注 | `agentic.ticket:read`，做决定时另需 `agentic.attention:update` |
| 负责人     | 回滚产物到上一版、撤销上一次出站并补发更正消息、处理 gone 对账  | 工单详情产物区               | `agentic.artifact:create`；撤销另需 `agentic.ticket:update`    |
| 平台管理员 | 配置出站载荷白名单、回放脱敏字段、gone 告警目标与内部写入时间窗 | 策略配置                     | `agentic.policy:update`                                        |

- 权限判定只在服务端完成，界面按钮的禁用与隐藏只是展示；产物、出站记录与效果账本按 Space 隔离，与资源所属空间没有成员关系的用户看到的是「不存在」。

### A3 功能逻辑与判定

**产物版本链**

| 规则     | 判定与行为                                                                     | 失败分支                                            |
| -------- | ------------------------------------------------------------------------------ | --------------------------------------------------- |
| 版本号   | 按「工单 + 产物类型」从 1 递增，新版本号由服务分配，调用方不得指定             | 并发写入同一版本号 → 唯一冲突后重试，不覆盖历史     |
| 只追加   | 历史版本负载不修改、不删除；修正只能追加新版本                                 | 请求删除或覆盖历史 → 拒绝                           |
| 状态     | 新建为草稿；人确认后为已确认；被新版本替代后为已替代                           | 已替代再确认 → 拒绝；同类型同时只允许一个已确认版本 |
| 回滚     | 取同类型上一版内容追加新版本并确认，同时把当前最新版置为已替代；版本号继续递增 | 不足两个版本 → 拒绝；工单已结束 → 拒绝              |
| 低分草稿 | 产物质量分低于阈值时不落产物，只建人工复核关注，本次运行结束                   | 关注创建失败 → 本次运行按失败上报，不静默交付       |

**确认与出站**

| 规则       | 判定与行为                                                                                               | 失败分支                                                |
| ---------- | -------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| 确认前提   | 同一工单的开放关注全部回答后才允许确认最新任务产物；任一未答时保持草稿，确认后生成出站消息并推进后续工作 | 仍有未答关注 → 不推进；并发回答 → 只有一次进入推进      |
| 修改       | 以修改说明追加任务产物新版本，确认新版本、替代旧版本，再生成出站消息                                     | 新版本落盘失败 → 旧草稿保持原状态，不确认               |
| 驳回       | 结束工单、丢弃该工单的预生成产物，并向来源会话发送驳回原因消息                                           | 消息发送失败 → 走出站失败分支，不改变已结束状态         |
| 载荷白名单 | 出站消息只含策略声明字段（结论、摘要、链接与产物标识）；未声明一律不出现；白名单为空视为只发确认通知     | 产物缺少声明字段 → 跳过该字段；全部跳过 → 只发确认通知  |
| 出站目标   | 只向该工单 Channel 的会话发送文本或卡片；不写来源系统的业务表格、不修改来源字段                          | 来源实例不可用 → 出站转 gone；通道缺失 → 不发送并建关注 |
| 幂等       | 同一工单同一产物版本的出站使用固定幂等键，重复触发返回同一结果                                           | 并发重复出站 → 后到者命中账本，不重复调用外部           |

**撤销出站**

| 规则     | 判定与行为                                                                                                   | 失败分支                                        |
| -------- | ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------- |
| 权限     | 必须同时具备更新工单与写产物两项权限                                                                         | 缺任一权限 → 拒绝，不产生新版本                 |
| 前置状态 | 工单必须进行中，最新产物必须已确认，且存在上一版本                                                           | 已结束、最新未确认、无上一版本 → 拒绝并提示原因 |
| 行为     | 取上一版内容追加新版本、确认、替代当前版，再向来源会话发送一条说明撤销的更正消息；不修改来源字段，过程可回放 | 更正消息发送失败 → 走出站失败分支；版本链不回退 |
| 重复提交 | 请求完成前禁止重复提交；成功后再撤销以当前链最新两版为基准，每次追加版本，不删除历史                         | 并发撤销 → 只有一次成功，其余冲突提示刷新       |

**效果账本与出站**

| 关注点   | 效果账本                           | 出站消息                                   |
| -------- | ---------------------------------- | ------------------------------------------ |
| 回答什么 | 这次外部调用是否已发生、结果是什么 | 这条消息是否已送达、失败几次、下次何时重试 |
| 幂等键   | 空间内唯一，重放前先查             | 空间内唯一，重复入队返回原消息             |
| 状态     | 待执行、成功、可重试失败、gone     | 待发、已发送、gone                         |
| 职责     | 成功结果可回放，避免重复调用外部   | 记录投递状态、失败次数、重试时间与错误     |

| 规则       | 行为                                                                                                            | 失败分支                                                |
| ---------- | --------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------- |
| 写入顺序   | 系统在事务内先登记效果与幂等键，提交后由效果队列执行外部调用，成功后再补记出站已发送                            | 登记失败 → 不调用外部，整条消息本轮失败并留痕           |
| 崩溃窗口   | 外部已成功、出站未记成功时，下一轮命中效果账本成功结果直接补记，不再调用外部                                    | 效果账本查询失败 → 本轮跳过，消息保持待发               |
| 结果未知   | 效果停留在待执行超过 120 秒视为结果未知，转 gone，要求人工对账                                                  | 未对账前不自动重发；对账后需重发只能新建消息            |
| 重试       | 可重试失败按 30 秒、60 秒、120 秒、240 秒退避，最多 5 次                                                        | 达到 5 次 → 转 gone；429 可重试，其余 4xx 直接 gone     |
| gone       | 来源实例不可用、永久性协议错误、结果未知都转 gone，不再调度                                                     | 不自动重发；保留错误原因与最后状态                      |
| 限流与暂停 | 同一来源实例每秒最多 10 条；连续 10 次失败即暂停来源并记录健康异常                                              | 超限本轮停止、消息保持待发；来源暂停后新消息直接 gone   |
| 失败降级   | gone 时写审计、给负责人建关注、按策略投递一条告警消息；告警同走消息链路、幂等键按原消息派生，自身 gone 不再递归 | 未配置告警目标 → 只保留关注与审计；配置缺失不阻塞主链路 |
| 出站适配   | 消息与卡片共用同一发送实现，按消息 id 幂等；只有永久不可达返回 gone，其他失败重试；同一会话保序                 | 越序失败超过阈值才允许后续消息越过                      |

**产物与出站审计**

| 规则     | 行为                                                                                                         | 失败分支                                        |
| -------- | ------------------------------------------------------------------------------------------------------------ | ----------------------------------------------- |
| 审计范围 | 产物写入、回滚、撤销、出站 gone 都写审计，记录操作者、动作、资源标识、版本、策略版本与追踪标识               | 审计写入失败 → 主流程继续，但必须告警           |
| 不落正文 | 审计只记录产物标识、类型、版本与派发标识，不落产物正文、模型推理过程、完整文档正文                           | 需要正文时按权限回查版本链，不复制进审计        |
| 脱敏截断 | 回放中的工具入参与出站载荷按脱敏字段与默认敏感键递归替换，字符串再过个人信息规则，超 4000 字符只留截断与预览 | 脱敏规则读取失败 → 按默认敏感键处理，不中断回放 |
| 行级     | 审计与回放同样按 Space 成员关系过滤；无可见记录时按「不存在」返回                                            | 越权查询 → 不可见，不泄露资源存在性             |

### A4 状态与数据流转

| 对象     | 状态                              | 状态变化                                                     | 失败与边界                                     |
| -------- | --------------------------------- | ------------------------------------------------------------ | ---------------------------------------------- |
| 产物     | 草稿 / 已确认 / 已替代            | 新建草稿；人确认转已确认；出现新版本时旧版转已替代           | 已替代不可再确认；工单结束后不再接受回滚与撤销 |
| 效果     | 待执行 / 成功 / 可重试失败 / gone | 待执行 → 成功或失败；失败可重试；超时或永久失败转 gone       | gone 不再执行；结果未知需人工对账              |
| 出站消息 | 待发 / 已发送 / gone              | 待发 → 已发送；可重试失败保持待发并更新下次时间；超限转 gone | gone 不再调度；来源暂停时新消息直接 gone       |

| 链路                | 输入                     | 状态变化                                         | 输出                   | 失败分支                                               |
| ------------------- | ------------------------ | ------------------------------------------------ | ---------------------- | ------------------------------------------------------ |
| L6-1 出稿与确认     | 工单、线程上下文、策略   | 产物追加草稿版本；人确认后转已确认，出站消息入队 | 出站结果、后续工作流   | 低分不落产物；载荷白名单为空只发通知；投递失败保持工单 |
| L6-2 工作流与确认   | 已确认任务产物、相似工单 | 工作流产物落草稿；人确认后转已确认               | 已确认的工作流产物     | 预生成稿被丢弃；确认时工单已结束则跳过                 |
| L6-3 回滚           | 同类型上一版本           | 追加新版本并确认；当前版转已替代                 | 回滚后的新版本         | 不足两版、工单已结束拒绝；并发只成功一次               |
| L6-4 撤销出站       | 已确认产物与上一版本     | 追加新版本并确认；当前版转已替代；发送更正消息   | 恢复后的版本与更正消息 | 权限不足、状态不符拒绝；发送失败走失败分支             |
| L6-5 出站与崩溃恢复 | 出站结果与通知消息       | 待发 → 已发送；效果成功；崩溃窗口命中成功结果    | 外部系统收到一次       | 失败退避；gone 不再调度并告警；不重复发送              |

### A5 交互与异常

| 场景                       | 用户可见表现                                     | 系统后续                                         |
| -------------------------- | ------------------------------------------------ | ------------------------------------------------ |
| 产物列表                   | 展示类型、版本号、状态；回滚只在存在上一版时出现 | 工单已结束时回滚与撤销按钮禁用                   |
| 回滚或撤销成功             | 列表出现新版本，旧版本标为已替代                 | 新版本默认已确认；撤销时来源收到一条更正消息     |
| 无历史版本、缺权限或已结束 | 提示没有可回滚版本、缺少所需权限点或工单已结束   | 不产生新版本、不出站，状态不变；服务端拒绝并留痕 |
| 并发冲突                   | 提示该工单正在处理另一条操作，请稍后重试         | 只保留一次有效操作，其余不入库                   |
| 出站载荷无字段             | 只提示任务产物已确认，进入下一步                 | 不产生出站消息，不阻塞后续工作流                 |
| 来源不可用或通道缺失       | 工单继续推进；无法出站时负责人收到关注           | 出站转 gone；配置告警目标时收告警                |

### A6 扩展与接入点

| 类别       | 接入点                                                                                                        | 约束                                                                                                     |
| ---------- | ------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------- |
| 数据接入点 | 执行器写产物（工单、类型、负载、派发标识）                                                                    | 必须带幂等语义；版本由服务分配；类型限任务产物、工作流产物、分析、报告                                   |
| 数据接入点 | 出站载荷白名单与目标（策略字段、来源会话、卡片动作）                                                          | 只发白名单字段；目标必须来自来源实例配置；禁止在来源系统写业务表格、优先级、合并、发布、验收字段         |
| 数据接入点 | 效果登记与出站消息（幂等键、类型、目标、实例、会话地址、负载）                                                | 外部写必须先登记；同一幂等键只允许一次成功结果；地址属于该来源实例；负载不含明文密钥                     |
| 扩展点     | 新产物类型、新效果类型                                                                                        | 需同时扩展枚举、版本链读取、界面展示与审计字段；复用同一账本与权限时间窗                                 |
| 扩展点     | 新来源类型（自带 Channel）、新通知通道、共用发送实现                                                          | 必须实现发送与 gone 判定、地址校验、限流、失败计数；单来源能力归属该来源，仅多来源共用才提取共享 Channel |
| 接入禁止项 | 原地改删历史、跨工单写结果、同幂等键表达不同业务、自动重发 gone、静默跳过审计、密钥写入负载、回写来源业务表格 | 一律拒绝并留痕；gone 只能人工对账后新建消息                                                              |

## 三、技术设计（B）

### B1 模块与文件

### B2 数据表

本域归属三张表，总览见 [design.md](design.md) 第七节；三张表都以 `spaceId` 归属一个 Space，越界读写由数据访问层拒绝。

| 表                          | 关键字段                                                                                                                                               | 约束与索引                                                                                                       | 可变性与保留                    |
| --------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------- | ------------------------------- |
| `agentic_artifacts`         | id、ticketId、spaceId、kind、version、payload、status、assignmentId、createdAt                                                                         | `(ticketId, kind, version)` 唯一；`(ticketId, createdAt)`、`(spaceId, kind)`、`assignmentId` 索引；外键 Restrict | 只追加；永久保留，旧版本不清理  |
| `agentic_effects`           | id、spaceId、idempotencyKey、kind、target、status、result、createdAt、completedAt                                                                      | `idempotencyKey` 唯一；`(status, createdAt)`、`spaceId` 索引                                                     | 状态迁移；永久保留，供崩溃对账  |
| `agentic_outbound_messages` | id、spaceId、instanceId、targetId、channelKind、address、payload、idempotencyKey、status、attempts、nextAttemptAt、sentAt、error、createdAt、updatedAt | `idempotencyKey` 唯一；`(status, nextAttemptAt)`、`(instanceId, createdAt)` 索引；实例外键 Restrict              | 有状态；成功或 gone 30 天后清理 |

- 枚举取值：产物状态 draft/confirmed/superseded，效果 pending/succeeded/failed/gone，出站 pending/sent/gone，渠道类型 message/card；只在共享枚举与数据定义中维护。唯一约束由数据库兜底，代码侧不做「先查后写」的并发假设。

### B3 接口与队列

| 方法 | 路径                                     | 权限                                                           | 入参与幂等                                      | 失败分支                                                       |
| ---- | ---------------------------------------- | -------------------------------------------------------------- | ----------------------------------------------- | -------------------------------------------------------------- |
| POST | `/agentic/tickets/:id/artifacts/restore` | `agentic.artifact:create`                                      | 查询参数 kind（缺省任务产物）；回滚追加版本     | 工单不存在 404；工单已结束 409；不足两个版本拒绝               |
| POST | `/agentic/tickets/:id/artifacts/revoke`  | `agentic.artifact:create` + `agentic.ticket:update`            | 查询参数 kind（缺省任务产物）；以最新两版为基准 | 工单不存在 404；已结束、最新未确认、无上一版、并发冲突 409     |
| POST | `/internal/artifacts`                    | 能力令牌 + `agentic.artifact:create` + Space 范围 + 有效时间窗 | 工单、类型、负载、派发标识；版本由服务分配      | 令牌缺失 503；令牌无效或过期 401；范围拒绝 404；工单不存在拒绝 |
| POST | `/internal/effects/reconcile`            | 能力令牌                                                       | limit 1–500；把超时待执行效果转 gone            | 令牌缺失 503；令牌无效 401                                     |

| 执行面   | kind                        | 生产方                             | 执行方                                  | 幂等与重试                             |
| -------- | --------------------------- | ---------------------------------- | --------------------------------------- | -------------------------------------- |
| 效果队列 | 出站消息、卡片、gone 告警等 | `application/outbox`（事务提交后） | `infrastructure/effects`（worker 装配） | kind+key 唯一；指数退避；永久失败 gone |

- 效果与出站的重试语义由队列消费统一实现：先查账本，再调用 Channel，成功后记回执；永久失败只写一次 gone 与告警。队列名统一登记在 `packages/shared/src/agentic/queues.ts`；Channel 发送实现归属来源，不设独立接入模块。

### B4 运行时与框架

| 项       | 设计                                                                                                                         |
| -------- | ---------------------------------------------------------------------------------------------------------------------------- |
| 进程归属 | Engine 写路径在 api 与 worker 双入口可用；效果执行、出站派发与周期对账在 worker 装配                                         |
| 写路径   | Engine 事务内写效果与幂等键 → 提交后执行外部调用 → 成功记回执；崩溃窗口由账本命中消除                                        |
| 幂等     | 效果按 kind+key 唯一；出站按幂等键唯一；待执行并发调用直接拒绝，避免多副本重复发送                                           |
| 失败分类 | 传输层把 4xx（429 除外）、协议缺字段与永久不可达判为 gone；网络错误、5xx、429 交给退避重试；gone 写审计并建负责人关注        |
| 时间边界 | 效果待执行超 120 秒视为结果未知；出站最多 5 次尝试；连续失败 10 次暂停来源；超限停止本轮并保持待发                           |
| 预算边界 | 重试次数与结果未知窗口是投递幂等边界，不作为单次执行的 token、时长或工具次数上限；执行期风险由停滞检测、取消与成本可观测承担 |
| 审计     | 产物写入、回滚、撤销、gone 分别记录运行级审计；审计失败只告警，不改变业务结果                                                |
| 授权     | 回滚与撤销走权限守卫；内部写入顺序为能力令牌、能力、Space 范围、有效时间窗                                                   |
| 出站     | 按来源类型选择 Channel；出站请求受地址白名单与私网策略约束，私网目标默认阻断，需显式豁免                                     |

### B5 配置与部署

| 配置项                                                                                    | 位置与默认值                               | 作用                                                          |
| ----------------------------------------------------------------------------------------- | ------------------------------------------ | ------------------------------------------------------------- |
| `OUTBOUND_RATE_PER_SECOND`                                                                | 环境变量，默认 10                          | 每来源实例每秒出站条数上限                                    |
| `LARK_API_BASE`、`LARK_APP_ID`、`LARK_APP_SECRET`                                         | 环境变量；密钥只经部署注入                 | 飞书 Channel 基地址与应用凭据；不进入产物、审计或通知载荷     |
| `OUTBOUND_ALLOW_PRIVATE_HOSTS`                                                            | 环境变量，默认空                           | 出站私网豁免清单；仅本地联调显式开启                          |
| `AGENTIC_RETENTION_APPLY`                                                                 | 环境变量，默认 `false`                     | 保留清理开关；与确认串同时满足才允许物理删除                  |
| `outboundPayloadFields`、`auditRedactFields`、`goneAlertTargets`、`capabilityTokenWindow` | 策略规则，缺省空数组、不告警、窗口 15 分钟 | 出站载荷白名单、回放脱敏字段、gone 告警目标与能力令牌有效窗口 |

- 部署形态：api 与 worker 同镜像双入口；效果执行与 Channel 派发只在 worker 装配；数据库不可用时 worker 停止消费，恢复后按幂等键重放。能力令牌校验公钥由部署注入，只存引用，不进入业务表与日志。

### B6 实现决策索引

| ADR      | 结论                                                       |
| -------- | ---------------------------------------------------------- |
| ADR-0038 | 出站地址受 URL 策略约束，私网目标默认阻断。                |
| ADR-0046 | 撤销不原地改字段，以上一版内容追加新版本。                 |
| ADR-0049 | 内部运行契约统一鉴权，写操作统一落审计。                   |
| ADR-0052 | 内部写入按能力、Space 范围与有效时间窗校验。               |
| ADR-0054 | 保留清理默认只预检，出站成功或 gone 记录 30 天后显式删除。 |
| ADR-0060 | 回滚只要求写产物权限；撤销同时要求更新工单与写产物权限。   |
| ADR-0061 | 权限时间窗作用于内部写入动作，非法配置按拒绝处理。         |
| ADR-0062 | 工具入参与出站载荷脱敏、超长截断后进入审计，供轨迹展开。   |
| ADR-0067 | 效果账本管外部调用幂等，出站状态管投递与重试。             |
| ADR-0068 | 出站 gone 按消息幂等键投递一次告警，告警自身失败不再递归。 |
| ADR-0070 | 队列 jobId 中的冒号统一净化，保留可读前缀与去重语义。      |
