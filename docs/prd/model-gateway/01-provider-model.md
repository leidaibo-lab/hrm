## 二、产品规格（A）

### A1 功能目标与非目标

目标：provider 可注册与启停；逻辑模型可声明候选与能力；价格可人工配置并以目录价兜底；多币种可按汇率折算；目录可同步且失败可观测。

非目标：不决定何时调用；不做任务调度；不做业务语义；不做预算配额；不做外部汇率源同步。

### A2 角色与入口

| 角色       | 入口             | 权限                   | 可做什么                                    |
| ---------- | ---------------- | ---------------------- | ------------------------------------------- |
| 平台管理员 | 控制台模型网关页 | `model.gateway:manage` | 维护 provider、模型、候选、价格、汇率、目录 |
| 空间负责人 | 控制台模型网关页 | `model.gateway:read`   | 查看本空间用量与成本                        |
| agentic    | 运行时解析       | 能力令牌               | 按逻辑模型取候选链                          |

### A3 功能逻辑与判定

| 规则     | 判定与行为                                                     | 失败分支                     |
| -------- | -------------------------------------------------------------- | ---------------------------- |
| provider | 名称、slug、协议、地址必填；slug 唯一                          | 重复 409；缺失 400           |
| 凭据     | 只保存密文；调用瞬间解密；页面只显示是否配置                   | 解密失败告警并按配置错误处理 |
| 逻辑模型 | logicalKey 唯一；停用即不可解析；maxAttempts 默认 3            | 重复 409；停用 409           |
| 候选     | 绑定 provider 与 providerModelId；按 priority 排序；三元组唯一 | 重复 409；无启用候选不可解析 |
| 能力     | 能力事实落候选；请求按 requirement 过滤                        | 无满足者返回能力不支持       |
| 手动价   | 按生效时间追加；同候选同来源同时间唯一                         | 重复 409                     |
| 目录价   | models.dev 同步写入；费率未变跳过；不覆盖手动价                | 同步失败保留旧数据           |
| 汇率     | 按币种对追加；rate_to_base 为 1 原币折合 USD；只追加           | 缺汇率时成本为空并告警       |
| 目录     | 可预览、同步、查看记录；未匹配候选可观测                       | 上游不可达 503，保留旧数据   |

### A4 状态与数据流转

| 对象     | 状态                                | 说明                          |
| -------- | ----------------------------------- | ----------------------------- |
| provider | enabled/disabled × healthy/degraded | 停用或 open 时不参与路由      |
| 逻辑模型 | enabled/disabled                    | 停用后不可被解析              |
| 候选     | enabled/disabled                    | 历史用量保留                  |
| 价格     | 生效/历史                           | 只追加；按 effectiveFrom 取用 |
| 汇率     | 生效/历史                           | 只追加；按 effectiveFrom 取用 |
| 目录同步 | success/failed/partial              | 只追加；失败不清旧数据        |

### A5 交互与异常

列表展示 provider、健康、启停、候选数与最近同步时间；凭据只显示是否配置；重复配置 409；不存在 404；未授权 403；目录不可达 503 并提示可手动录入；价格区显示「手动/目录/缺失」三态。

### A6 扩展与接入点

新增 provider 协议适配；新增候选；新增能力声明；新增价格维度；新增汇率来源。边界：模型网关不感知工单与空间策略。

## 三、技术设计（B）

### B1 模块与文件

路径相对 `apps/api/src/modules/model-gateway/`：controller 六个；`dto/`；`domain/` 放实体、仓储端口与错误；`application/` 放 provider/model/price/fx/catalog 用例；`infrastructure/` 放 Prisma 仓储、快照、目录客户端、连通性探测。

### B2 数据表

`model_gateway_providers`、`model_gateway_logical_models`、`model_gateway_candidates`、`model_gateway_prices`、`model_gateway_fx_rates`、`model_gateway_catalog_syncs`；字段与约束见 [design.md](design.md) 第七节。

### B3 接口与队列

`/api/v1/model-gateway/providers`、`/models`、`/candidates/:id/prices`、`/fx-rates`、`/catalog`；权限 `model.gateway:read` / `model.gateway:manage`；目录同步使用队列任务，失败重试两次并记录。

### B4 运行时与框架

链解析使用配置快照；快照按 TTL 与写失效刷新；目录客户端只在同步任务中访问外网；领域层不依赖运行时 SDK。

### B5 配置与部署

凭据由部署注入主密钥；目录同步计划、超时与重试由配置提供；汇率由管理员维护；目录数据来源标注 models.dev。
