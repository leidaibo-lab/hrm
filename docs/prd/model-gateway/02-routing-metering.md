## 二、产品规格（A）

### A1 功能目标与非目标

目标：按候选链路由；可重试错误自动转移；provider 限流与 429 分类；每次尝试可归因；成本可汇总且来源可追溯；流式输出不重复。

非目标：不决定何时调用；不做任务调度；不做业务授权；不做预算配额。

### A2 角色与入口

| 角色       | 入口         | 权限                   | 可做什么             |
| ---------- | ------------ | ---------------------- | -------------------- |
| 平台管理员 | 控制台用量页 | `model.gateway:manage` | 查看用量、成本与健康 |
| 空间负责人 | 控制台用量页 | `model.gateway:read`   | 查看本空间用量与成本 |
| agentic    | 运行时调用   | 能力令牌               | 按逻辑模型调用       |
| 调度器     | 降级信号     | 内部能力               | 做背压，不实现配额   |

### A3 功能逻辑与判定

| 规则       | 判定与行为                                                | 失败分支                   |
| ---------- | --------------------------------------------------------- | -------------------------- |
| 候选选择   | 过滤启用、健康、熔断、能力后按优先级取前 N（maxAttempts） | 全部不可用返回无候选       |
| 失败转移   | 交给 mastra 的候选链；每条 maxRetries 为 0                | 记录每次尝试               |
| 重试预算   | 链长上限默认 3；流错误重试覆盖为 0，防多层放大            | 全部失败返回聚合错误       |
| 每分钟限额 | 按 provider 计数；超限拒绝                                | 返回限流错误               |
| 并发限额   | 按 provider 占槽与释放；超时拒绝                          | 返回限流错误               |
| 上游 429   | 解析 Retry-After；打开熔断；同 run 转移                   | 可转移                     |
| 熔断       | 连续瞬时失败或 429 打开；半开单探针；成功复位             | 打开期间不参与路由         |
| 计量       | 每次尝试记录 tokens、延迟、状态、归因、价格与汇率快照     | 入队失败告警并可对账       |
| 成本       | 手动价 → 目录价；原币成本按汇率折算 USD                   | 缺价/缺汇率标记并告警      |
| 错误返回   | 全部失败时返回聚合错误：首个永久错误优先，否则最后一条    | 异常被包装时退化为最后一条 |
| 流式       | 首 chunk 前可转移；首 chunk 后不转移，错误转为终止事件    | 不重放已输出内容           |
| 直调       | 单候选调用，内置限流与计量，无 fallback                   | 不满足能力时拒绝           |

### A4 状态与数据流转

| 对象     | 状态                                        | 说明                |
| -------- | ------------------------------------------- | ------------------- |
| provider | healthy / degraded / open                   | open 期间不参与路由 |
| 用量     | success / failed / rate_limited / cancelled | 只追加              |
| 价格     | 生效 / 历史                                 | 历史不重算          |
| 汇率     | 生效 / 历史                                 | 历史不重算          |

### A5 交互与异常

用量页按空间、Agent、逻辑模型、候选、状态与时间筛选；限流提示稍后重试；降级显示健康与恢复时间；缺价与缺汇率单独标记；凭据不展示。

### A6 扩展与接入点

新增错误分类；新增限额维度；新增成本维度；新增健康探测策略；新增汇率来源。边界：调度器只消费信号。

## 三、技术设计（B）

### B1 模块与文件

路径相对 `apps/api/src/modules/model-gateway/`；链解析在 `application/`，熔断、限流、mastra 适配、队列与快照在 `infrastructure/`；领域选择逻辑收敛在逻辑模型实体。

### B2 数据表

`model_gateway_usages` 记录每次尝试与成本快照；`model_gateway_prices` 与 `model_gateway_fx_rates` 提供定价；provider 健康状态存于 `model_gateway_providers`。

### B3 接口与队列

`POST /api/v1/model-gateway/usages/query` 与 `GET /usages/summary` 提供报表；用量异步入队，jobId 为 callId；失败进死信并告警。

### B4 运行时与框架

mastra 消费 `ModelWithRetries[]`；每条 maxRetries 为 0；Agent 关闭默认流错误重试；网关提供限流、凭据解密、流守卫与熔断；降级信号由导出面提供。

### B5 配置与部署

链长、限额、熔断阈值、探测间隔、目录同步计划与用量队列开关由配置提供；Redis 不可用时限流放行并告警。

### B6 实现决策索引

| ADR      | 结论                                  |
| -------- | ------------------------------------- |
| ADR-0015 | 限流、计量与计价在网关内完成          |
| ADR-0084 | 重试与 fallback 归 mastra；熔断归网关 |
