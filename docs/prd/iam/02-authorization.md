## 二、产品规格（A）

### A1 功能目标与非目标

目标：动作权限与数据可见性分离；查询谓词前置；越权不泄露；Agent 令牌最小化；允许与拒绝可审计。

非目标：不做关系型授权（共享、委派、文档 ACL）；不做字段级策略引擎；不做多租户。

### A2 角色与入口

| 角色       | 入口           | 权限     | 可做什么                       |
| ---------- | -------------- | -------- | ------------------------------ |
| 普通用户   | 业务页面与接口 | 权限点   | 在可见空间内执行被授予的动作   |
| 平台管理员 | 全局           | 权限点   | 跨空间管理，读业务需审计       |
| Agent      | 工具调用       | 能力令牌 | 只能访问令牌范围内的资源与工具 |

### A3 功能逻辑与判定

| 规则     | 判定与行为                                                    | 失败分支            |
| -------- | ------------------------------------------------------------- | ------------------- |
| 动作     | 权限点缺失直接拒绝                                            | 403                 |
| 数据     | 资源 spaceId 必须在可见空间集合内                             | 404（不泄露存在性） |
| 对象     | 应用服务对具体资源再判定；判定入口唯一                        | 404                 |
| 字段     | 视图映射脱敏                                                  | 字段不返回          |
| 幂等     | 重复判定与重复拒绝不改变状态                                  | 记录审计            |
| 令牌     | 绑定 assignment、空间、工单、工具、动作与有效期；子代理取子集 | 过期或越界拒绝      |
| 拒绝响应 | 越权与不存在一致；不区分原因                                  | 统一 404            |

### A4 状态与数据流转

| 对象     | 状态               | 说明                   |
| -------- | ------------------ | ---------------------- |
| 权限点   | 有效 / 废弃        | 废弃不物理删           |
| 令牌     | 有效 / 过期 / 撤销 | 随 assignment 状态     |
| 判定结果 | 允许 / 拒绝        | 拒绝写审计，不返回原因 |

### A5 交互与异常

越权读取：列表不出现、详情按不存在；写操作越权：404 与状态冲突 409 分开；Agent 工具拒绝返回结构化不存在，不抛系统错误；前端隐藏入口不作为安全边界。

### A6 扩展与接入点

新增资源类型需登记可见性规则；新增动作需登记权限点；关系型授权在出现共享/委派时另立设计，接口不变。

## 三、技术设计（B）

### B1 模块与文件

路径相对 `apps/api/src/modules/iam/`：授权入口 `application/authorization.service.ts`；令牌校验在 `application/` 与工具适配；关系型适配预留在 `infrastructure/authorization/`。

### B2 数据表

判定依赖 `iam_space_members`、`iam_role_assignments`、`iam_permission_points`；资源表只使用 spaceId，不复制权限数据。

### B3 接口与队列

无独立端点；授权入口供其它模块应用层调用；令牌由派工流程签发，工具调用时校验；无业务队列。

### B4 运行时与框架

CASL 每次请求重建 ability；Space 谓词由仓储层统一注入；对象判定在应用服务；可选 RLS 按 spaceId；不引入关系型授权服务。

能力令牌为 Ed25519 JWT，claim 契约：

| claim               | 含义                                |
| ------------------- | ----------------------------------- |
| `sub`               | 执行主体（assignment 标识）         |
| `assignmentId`      | 派工绑定                            |
| `spaceId`           | 允许访问的空间                      |
| `ticketId`          | 允许访问的工单                      |
| `allowedTools`      | 工具白名单                          |
| `capabilities`      | 动作/能力上限                       |
| `iat` / `exp`       | 签发与过期；有效期不超过 assignment |
| `jti` / `parentJti` | 令牌标识与父令牌（子代理衰减用）    |

签名密钥由部署配置；校验失败按未授权处理，不泄露原因。

### B5 配置与部署

令牌签名密钥与有效期由部署配置；拒绝审计写入平台审计；RLS 默认关闭。
