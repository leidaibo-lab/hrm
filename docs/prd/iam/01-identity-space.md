## 二、产品规格（A）

### A1 功能目标与非目标

目标：用户可维护与挂起；角色与权限点可授予与撤销；Space 可创建与归档；空间成员可增删；变更下一请求生效。

非目标：不做多租户与部门；不做 SSO；不做关系型共享与委派。

### A2 角色与入口

| 角色       | 入口         | 权限                    | 可做什么                 |
| ---------- | ------------ | ----------------------- | ------------------------ |
| 平台管理员 | 管理端用户页 | `iam.user:manage`       | 维护用户、状态与角色授予 |
| 平台管理员 | 管理端角色页 | `iam.role:manage`       | 维护角色与权限点         |
| 平台管理员 | 管理端导航页 | `iam.navigation:manage` | 维护导航覆盖             |
| 空间负责人 | 管理端空间页 | `iam.space:manage`      | 维护空间与成员           |

### A3 功能逻辑与判定

| 规则   | 判定与行为                                         | 失败分支                 |
| ------ | -------------------------------------------------- | ------------------------ |
| 用户   | 用户名与邮箱唯一；挂起后不可登录                   | 重复或缺失拒绝           |
| 角色   | code 唯一；内置角色不可删；角色授予需权限点存在    | 未知权限点拒绝           |
| 权限点 | 目录为代码唯一事实源；删除标废弃不物理删           | 非法 code 拒绝           |
| 空间   | key 唯一；有资源时不可删；归档后不再出现在新建下拉 | 冲突 409                 |
| 成员   | (空间, 用户) 唯一；移出后立即不可见                | 重复授予幂等；不存在 404 |
| 生效   | 角色或成员变更下一请求生效                         | 无缓存滞后               |

### A4 状态与数据流转

| 对象     | 状态               | 说明           |
| -------- | ------------------ | -------------- |
| 用户     | active / suspended | 挂起后拒绝登录 |
| 角色授予 | 有效 / 撤销        | 撤销即生效     |
| 空间     | active / archived  | 归档不删除历史 |
| 成员     | active / removed   | 移出即不可见   |

### A5 交互与异常

用户列表展示状态与角色；重复授予幂等；撤销不存在关系返回未删除；空间成员增删即时刷新；越权 403；不存在 404。

### A6 扩展与接入点

新增权限点；新增空间属性；新增身份来源（只影响会话，不改角色模型）。边界：本域不做资源对象判定，交给授权服务。

## 三、技术设计（B）

### B1 模块与文件

路径相对 `apps/api/src/modules/iam/`：入口为用户、角色、权限点、空间与导航 controller 及 `dto/`；领域 `domain/`；应用 `application/`；基础设施 `infrastructure/`。

### B2 数据表

`iam_users`、`iam_roles`、`iam_permission_points`、`iam_role_permission_points`、`iam_user_roles`、`iam_role_assignments`、`iam_spaces`、`iam_space_members`、`iam_navigation_nodes`；约束见 [design.md](design.md) 第七节。

### B3 接口与队列

`/iam/users`、`/iam/roles`、`/iam/permission-points`、`/iam/navigation-nodes`、`/iam/spaces`、`/iam/spaces/:id/members`；权限点见功能篇；无业务队列。

### B4 运行时与框架

启动时把权限点与导航目录同步到投影表；会话每请求实时展开权限；成员变更即时生效。

### B5 配置与部署

内置角色与权限点随代码发布；空间与成员为运行数据；挂起与归档保留历史。
