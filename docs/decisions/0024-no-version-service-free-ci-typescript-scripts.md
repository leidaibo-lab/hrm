# ADR-0024 移除并发版本字段与无服务 CI

> 状态：已接受 · 日期：2026-11-08 · 级别：L3

## 决定

依据用户当次明确指令：移除 Role、ModelProvider、ProviderModel 的 version 字段及前后端消费；保留按修改意图保存，接受同字段并发写入以后提交为准。已应用过的新增列迁移不改写，使用 Prisma 生成的后续删除列迁移表达最终状态。

CI 禁止构建、数据库和其他常驻服务，不运行迁移、持久化集成或启动 API/Redis。保留文档、架构、lint、源码类型检查与单元测试；Prisma 仅生成客户端，OpenAPI 仅装载 controller 元数据并注入替身离线导出，前端据此生成 SDK。CI 使用专门的源码检查入口，避免 Turbo 的隐式 shared build。DB 集成测试仍可由开发者显式提供测试数据库在本地执行。

用户要求工程脚本统一 TypeScript 与 tsx：scripts 下脚本由 .mjs 迁为 .ts，独立严格类型检查，共享脚本类型与实现同源；更新命令、引用、检查和保护基线。

## 被否决的选项

- 保留可选 version 或改名隐藏：不符合移除字段的要求。
- 只删 CI services，继续执行 Turbo build 依赖或启动 API：仍然间接构建或依赖外部服务。
- 直接手改生成客户端/删除事务断言：会破坏契约管线和原子性验证；采用离线生成并保留本地集成用例。
- 用 tsx 执行脚本却不检查其类型：无法落实 TypeScript 的实际约束。

## 后果与回滚

不再提供乐观锁冲突检测；角色名称更新不会覆盖权限，但同字段更新可能覆盖。CI 不证明生产构建或数据库正确性，相关本地验证必须如实报告。保护基线、脚本入口和 CI 范围变更已由本次指令授权。回滚需同步源码/schema/消费方和新迁移，不编辑已应用迁移；不修改其他数据库，不推送或更改远端设置。
