# ADR-0001 文档结构治理

> 状态：已接受（「删除 ADR 目录、决定内联治理文件」条款已被 ADR-0007 取代） · 日期：2026-10-31 · 级别：L3

## 决定

目录改为 `process/`、`conventions/`、`reference/`、`research/`；移除 AI 专属前缀命名；删除自研文档检查脚本与 ADR 目录；现行文档压到 8 篇；每篇现行文档加三元组。

## 被否决的选项

保留旧前缀命名（命名按受众而非功能，与 agent-first 无关）；全平铺目录（丢失目录语义，路由反而变贵）；保留自研检查脚本（维护成本高于收益，阶段 1 改用标准工具）；保留阶段 0 的 5 份 ADR（无源码支撑，且其中判断已被本次治理替代）。

## 后果

命令注册表不再有非 git 的可用命令；链接 / 路径 / 行数检查退回人工；"为什么"只保留 `docs/governance.md` 摘要与 `research/` 证据，不再逐条留档。
