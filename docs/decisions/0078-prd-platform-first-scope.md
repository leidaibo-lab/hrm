# ADR-0078 PRD 平台优先范围、验收复选框与统一版本

> 状态：已接受 · 日期：2026-11-17 · 级别：L3

## 决定

PRD 以 **Super-agent 平台能力**为第一优先，不以具体业务场景立项：

- 目标、非目标、场景、成功指标按平台能力表述；具体业务场景（需求澄清、Bug 分析、对话页面等）尚未接入，不在本期展开；
- 功能篇只写平台能力（来源接入、归并研判、工单派工、关注闸门、产物出站、控制台观测）；
- 参考 Source（Lark）用于验证主链路，不作为业务场景。

验收清单统一为**复选框列表**（`- [ ] AC-XX-NN <场景>：<期望>（证据：…；评审人：…）`），按功能分组，不再使用表格；`[x]` 表示已验证。

所有 PRD 文档（`index.md`、`design.md`、`NN-<域>.md`）共用同一版本号，本期统一为 `V3.0（2026-11-17）`；后续整份 PRD 统一升版并在各篇版本记录同步，禁止逐篇独立版本。

## 被否决的选项

- **业务场景先行**：业务尚未接入，先写业务需求会把未确定的场景固化成约束，违背平台优先。
- **验收继续用表格**：不便逐条勾选、评审与状态跟踪，且与复选框语义重复。
- **按篇独立版本**：同一 PRD 出现 V2.0/V3.0 混用，无法判断整体基线。

## 后果与回滚

- 更新 `_TEMPLATE.md`（验收格式与版本要求）、`documentation.md`（PRD 版本与验收规则）、`prd-consistency.spec.ts`（复选框解析、证据字段、版本一致性）。
- 检查设施变更随本 ADR 更新保护基线。
- 回滚：revert 本批提交，恢复表格验收与逐篇版本。
