# ADR-0007 决策记录迁移至 docs/decisions/

> 状态：已接受 · 日期：2026-10-31 · 级别：L3

## 决定

治理级决定改以轻量 ADR 逐条记录在 `docs/decisions/`：一条决定一个文件，命名 `NNNN-英文短名.md`，编号递增追加；头部一行 `> 状态：已接受 | 已取代 · 日期：YYYY-MM-DD · 级别：L0-L3`，取代关系写入被取代文件的「状态」行；正文三段：决定 / 被否决的选项 / 后果。ADR 是记录不是规范：不计入「现行文档 ≤ 10 篇」预算、不要求三元组、结构检查 glob 不含 `decisions/`。`docs/governance.md` 的「决策记录」收敛为追加规则与指针，不再内联决定正文；存量 6 条决定迁移为 ADR-0001~0006（原「按时间倒序追加」，反转编号即时间正序）。

## 被否决的选项

维持内联（`docs/governance.md` 迁移前 171 行、超出其 150 行预算，「决策记录」按设计只增不减，冲突必然复现；与 `documentation.md` 的超预算处理顺序「拆分为独立文件并在 `docs/index.md` 登记」矛盾）；拆单文件 `docs/decisions.md` 追加式搬迁（无界增长问题只是搬家，单文件路由越来越贵，单条决定无法独立标注取代状态）；维持原治理口径「不设 ADR 目录」（其否决理由——阶段 0 的 ADR 无源码支撑——对新决定已失效，存量决定均有真实 commit 背书）。

## 后果

新增治理决定 = 新建一个 ADR 文件，并同步修订被取代 ADR 的「状态」行、本文件（`docs/governance.md`）受影响条款及 `AGENTS.md`、`docs/index.md` 的引用；`governance.md` 回到 150 行预算内；ADR-0001 中「删除 ADR 目录、决定内联治理文件」条款由本决定取代，其余条款继续有效；`docs/index.md` 不逐条枚举 ADR，靠文件名 slug 与文件内标题路由；结构检查三条命令不变，预期输出仍为 `10`。
