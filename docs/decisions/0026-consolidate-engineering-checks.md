# ADR-0026 工程检查去重

> 状态：已接受 · 日期：2026-11-08 · 级别：L3

## 决定

用户确认优化已审阅的脚本方案：保留 docs、rules、protected 与共享 source-graph；drift 的 ADR/spec 清单检查归入 docs，audit:drift 改为 package.json 的三个命令组合。docs 导出无副作用的 checkDocs，CLI 与回归测试共用；API 架构测试只通过共享依赖图判断依赖，目录角色检查保留。删除无效 _versions 变量。原有门禁、保护范围和约束不减少。

## 被否决的选项

- 删除重复测试却不证明等价覆盖：用真实仓库通过和可回滚的违规样例补齐文档及各依赖方向反例。
- 删除 protected：本次保留辅助变更提醒，不冒充远端审批或语义检查。
- 为减少入口把全部逻辑合为一个大文件：文档、规则、保护和依赖分析仍各有独立职责。

## 后果与回滚

汇总不再隐藏子检查输出；ADR 和测试文件存在性不代表测试运行。检查实现仅一处，测试覆盖其正反例。回滚需同步命令、引用、测试和保护基线；不改业务代码、数据库或 CI 无构建无服务约束。
