- [产品总览](产品总览.md)：查看 HRM 整体边界、文档分层、招聘闭环和跨模块规则。
- [公共规范](公共规范/)：查看所有模块共同遵循的字段、权限、审计和数据治理规则。
- [招聘管理模块](模块/招聘管理/)：查看当前 MVP 的范围、PRD、用户故事和验收标准。

## 项目定位

pm-hrm 是面向 HRM 人资管理领域的 AI 产品管理与交付实践项目。项目通过 AI 辅助完成从产品发现到可验收交付的完整需求闭环。

HRM 是本项目实践的业务产品，整体规划包含工作台、招聘管理和绩效管理。

当前阶段只建设招聘管理模块 MVP，范围是从飞书职位发布完成后的职位建档，到候选人筛选、邀约、面试、评价和录用决策的完整闭环。工作台、账号、组织、权限和审计是本阶段的支撑能力；绩效管理暂不进入当前实现。

## AI 需求闭环

```text
产品发现 -> 假设验证 -> 需求澄清 -> PRD -> 用户故事
    -> 验收标准 -> 技术实现 -> 测试验证 -> 反馈迭代
```

AI 用于整理讨论、识别需求缺口、产出文档、拆解任务和辅助验证；业务负责人负责确认产品决策、权限边界和验收结果。

## 产出规则

产品讨论先形成草案，经过确认后再标记为结论。事实、假设、待验证问题和决策必须分开记录，避免把未经验证的想法当作需求。
