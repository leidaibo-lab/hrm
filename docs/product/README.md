# HRM 人资管理系统产品文档

本目录保存 HRM 人资管理系统的产品探索、需求和决策产物。

## 项目定位

HRM 是面向公司内部的人资管理系统，整体规划包含工作台、招聘管理和绩效管理。

当前阶段只建设招聘管理模块 MVP，范围是从飞书职位发布完成后的职位建档，到候选人筛选、邀约、面试、评价和录用决策的完整闭环。工作台、账号、组织、权限和审计是本阶段的支撑能力；绩效管理暂不进入当前实现。

## 建议文档

- `discovery.md`：目标用户、问题场景和访谈结论。
- `opportunity-solution-tree.md`：结果、机会、方案和实验。
- `product-strategy.md`：产品定位、价值主张和战略约束。
- `mvp-scope.md`：MVP 包含项、暂不做项和范围依据。
- `招聘协作MVP产品需求文档.md`：HRM 招聘管理模块 MVP 产品需求文档。
- `招聘协作MVP用户故事.md`：HRM 招聘管理模块 MVP 用户故事和验收标准。
- `metrics.md`：北极星指标、输入指标和业务指标定义。
- `decisions.md`：关键产品决策及其证据。

## 产出规则

产品讨论先形成草案，经过确认后再标记为结论。事实、假设、待验证问题和决策必须分开记录，避免把未经验证的想法当作需求。

## 当前草案

- `discovery.md`：关键假设对齐、落地风险和验证优先级。
- `security-and-permissions.md`：数据权限、审计和生命周期规则。
- `mvp-scope.md`：HRM 招聘管理模块 MVP 范围，明确飞书与 HRM 的职责边界。
- `decisions.md`：飞书承接招聘需求、审批和职位发布的产品决策。
